# HillsByte — Disable Ad Gates Patch

This patch removes ONLY ad-view requirements from:
1. Starting a task
2. Referral qualification/unlock, if an ad-watch requirement exists

Keep all other referral requirements unchanged:
- 50 XP
- 4 completed tasks
- Channel join
- First withdrawal

Keep normal rewarded-ad functionality unchanged, including the server-side 5-second minimum watch rule.

## Backend

`claim_task_attempt` must not require `sponsor_ad_required` and should return:

```js
sponsorRequired: false
```

for both existing and newly-created attempts.

`create_withdrawal_atomic` must not require 20 ad views before withdrawal.

## Frontend task-start

Find the task-start handler and remove any ad launch caused by:

```js
task.sponsor_ad_required
task.sponsorRequired
sponsorRequired
```

Task start should call the existing task-start API directly and then open the task/timer.

Do NOT remove normal rewarded-ad calls:

```js
start_ad
complete_ad
```

## Referral

Find referral qualification/unlock logic and remove ONLY conditions requiring ad views, such as:

```js
ad_views >= N
today_ad_views >= N
required_ad_views
ads_watched
ad_watch_requirement
```

Do NOT remove:
- 50 XP
- 4 tasks
- channel join
- first withdrawal

If no ad-view referral requirement exists, make no referral change.

## Do not change

- referral commission calculations
- referral capture/linking
- XP calculations
- task completion/rewards
- withdrawal minimums/fees
- withdrawal daily limits
- country targeting
- Telegram verification
- 5-second ad-session validation
- normal ad rewards

Expected behavior:

Start Task → server validation → task opens immediately

Referral qualification → existing non-ad requirements only

Rewarded ad → existing ad flow + 5-second server-side validation
